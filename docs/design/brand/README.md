# Logo Clarune

Logo chữ C gợi hình hội thoại, dùng màu accent của design system. Mỗi bản có cả SVG và PNG; ưu tiên SVG.

| Tệp | Dùng cho |
|---|---|
| `clarune-logo` | Logo đầy đủ trên nền sáng |
| `clarune-logo-dark` | Logo đầy đủ trên nền tối |
| `clarune-compact` | Bản gọn trên nền sáng, chỗ hẹp |
| `clarune-compact-dark` | Bản gọn trên nền tối |
| `clarune-mark` | Chỉ biểu tượng: favicon, rail tablet |
| `91-25712`, `91-25718` | Ảnh xuất trực tiếp từ node Figma cùng số |
